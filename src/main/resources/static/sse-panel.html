ℹ️ Sobre Server-Sent Events (SSE)

SSE es una alternativa a WebSocket optimizada para notificaciones unidireccionales (servidor → cliente). No requiere que el cliente envíe datos.

SSE Ventajas: HTTP estándar, reconexión automática, menos overhead, más simple.
WebSocket Mejor para: Comunicación bidireccional, chat, juegos.
